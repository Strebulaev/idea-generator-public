# Авто-аппрув HITL после таймаута

## Решение

Все HITL, кроме HITL-3, являются опциональными. При отсутствии решения пользователя в течение заданного таймаута выполняется авто-аппрув по системному вердикту.

Таймауты:

- HITL-1 — 1 час.
- HITL-2 — 1 час.
- HITL-3 — не имеет авто-аппрува, всегда требует ручного решения.

## Поведение при таймауте

1. Публичный poller проверяет возраст HITL issues каждые 5 минут.
2. Если issue создана более 1 часа назад и не имеет решения:
   - Оставляется комментарий: `⏰ Auto-approved after 1h timeout, proceeding with system recommendation: <verdict>`.
   - Добавляется лейбл `auto-approved`.
   - Создаётся `event` типа `hitl_auto_approved` со статусом `succeeded`.
   - Пайплайн продолжается по системному вердикту:
     - HITL-1 → ARCHIVE.
     - HITL-2 → ARCHIVE.
3. Если issue имеет комментарий `GO` / `NO-GO` / `CONFIRM` / `DISPUTE` — таймаут сбрасывается, решение обрабатывается как ручное.

## Настройка таймаутов

Таймауты задаются через переменные окружения в публичном репо:

- `HITL1_TIMEOUT_SECONDS` — по умолчанию 3600.
- `HITL2_TIMEOUT_SECONDS` — по умолчанию 3600.
- `HITL3_TIMEOUT_SECONDS` — не используется, так как HITL-3 не имеет авто-аппрува.

## Обоснование

- Авто-аппрув предотвращает зависание пайплайна при неактивном пользователе.
- 1 час — баланс между временем на реакцию и скоростью пайплайна.
- HITL-3 исключён, так как финальное go/no-go требует явного подтверждения.

## Исключения

- Если пользователь оставил комментарий `DISPUTE` до истечения таймаута — авто-аппрув не применяется.
- Если issue была закрыта вручную — таймаут не применяется.
